## 📌 Description
Podcast Aggregator & Streamer is a desktop RSS podcast manager for subscribing to show feeds, streaming episodes, and managing offline downloads.

---

## ✨ Features
- Subscribe to RSS podcast feeds with OPML import/export support
- Continuous background episode update checking and new episode alerts
- Built-in audio player with variable playback speed, skip silent sections, and sleep timer
- Offline episode downloader with automatic storage management
- Show catalog management, episode bookmarking, and listening history

---

## 🛠️ Tech Stack & Architecture
- **Language / Framework**: Python 3.10+ / Qt (PySide6 / PyQt)
- **Core Modules**: Modular engine architecture, async event dispatching, decoupled utility functions
- **Target OS**: Windows, macOS, Linux

## 🚀 Quick Start & Installation

### Prerequisites
- **Python**: Version 3.10 or higher installed
- **Git**: Installed for cloning repositories

### Setup Instructions
```bash
# 1. Clone the repository
git clone https://github.com/hsinidev/030-Podcast-Aggregator-Streamer.git

# 2. Navigate to project directory
cd 030-Podcast-Aggregator-Streamer

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Launch the Application
python app.py
```
*(Note: If `app.py` is absent, launch with `python main.py`)*
